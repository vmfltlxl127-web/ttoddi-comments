토큰 받는 법 (처음 한 번만)
  1. 작가 계정(keysbrown_)이 프로페셔널 계정(크리에이터/비즈니스)인지 확인 — 인스타 설정 → 계정 유형.
  2. developers.facebook.com/apps 에서 앱 만들기 → 사용 사례에서 Instagram(메시지·콘텐츠 관리) 선택.
  3. 앱 대시보드 → Instagram 이용 사례 → 통합 로그인이 포함된 API 설정으로 이동.
  4. 1단계에서 구성이 없으면 새로운 구성 만들기. 2단계 액세스 토큰 생성에서 keysbrown_ 옆 토큰 생성을 눌러 허용.
  5. 나온 토큰(EAA… 로 시작)을 복사해서 위 칸에 붙여넣기. 계정 ID는 2단계에 keysbrown_ 아래 적힌 숫자야.

토큰은 비밀번호랑 같아. 남한테 보내거나 캡처해서 올리지 마.
